# FoodMesh

FoodMesh is a hyperlocal food resilience web app that helps route surplus food from households and businesses to nearby people and community organizations before it becomes waste.

## Hackathon MVP

- Find food by ZIP code without requiring an account
- Share surplus food with low-friction intake
- AI-assisted food classification
- Accessibility-aware recipient matching
- Printable local food schedules
- Bulk donation path for businesses and organizations
- Package-date capture that preserves whether a label says best by, use by, sell by, expiration, or prepared on
- Future photo AI can prefill those same date fields, with user review before submission

## Design principles

- Dignified, hopeful, non-stigmatizing interface
- Keyboard- and screen-reader-friendly semantic structure
- Responsive on inexpensive phones, tablets, and library computers
- Physical accessibility information for pickup locations
- AI interprets messy real-world input; deterministic software handles hard matching constraints

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
